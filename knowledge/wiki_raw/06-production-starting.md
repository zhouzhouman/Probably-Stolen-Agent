## 生产配方

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/production-recipes

### 机制要点
- 本站明确声明：**这不是完整配方清单**，只是「已核实的路线索引」。配方在代码层由运行时构造，本地化文本、物品目录、运行时目录里都没有配方字段，因此完整条目清单取不到。
- 熔炉（普通）：**2 份废金属或金属矿石 → 1 块金属锭**；需要供电并过夜；矿石纯度高于废金属。
- 熔炉三类金属原料（废金属 / 金属矿石，共 2 份）可互相替换。
- 助熔剂是**可选纯度处理**，不替代金属原料：基础助熔剂消耗、高级助熔剂可重复使用。
- 熔炉高炉模组：**3 份材料 → 2 块金属锭**，纯度加成少 1 档，最低为 0；效果不能叠加。
- 熔炉垃圾处理模组：垃圾 → 废金属。
- 普通酿酒（酒瓶内发酵）：荧光莓 + 水 + 酒瓶；**1 把浆果 → 低级酒，2 把浆果 → 高级酒**。
- 酿酒发酵天数：**无酵母 4 天，标准酵母 2 天，超级酵母 1 天**。
- **发酵完成不生成额外酒瓶**（酒瓶在原瓶内状态变化）。
- 净水器：放入储水容器 + 能量 → 过夜净化。
- 水分收集器：提供容器 + 能量 → 过夜产水；性能影响产量，固定毫升数未实机核实。
- 水培：水容器 + 矿物质 + 电源 + 种子 → 达到该作物所需进度后收获；作物、特征与状态会改变过程，不统一按一两天计算。
- 化学加工：以当前可用设备区分工序，检查纯度；**旧蒸发器已于 2026-09-15 热修移除**。
- 蒸发器的物品名、说明、操作提示、溶剂回收模组目录项仍留在资源里，梦尘与咖啡因片的指南步骤仍把它写成必需环节——**这只是文本未清理**，不代表现版本仍可获得。
- 制作台配方形态：产出物 id + 产出数量 + 材料 id + 材料数量（材料数量默认 1），材料也可按标签集合匹配；制作台界面为**输入网格 10×16、输出槽位 3×3**。
- 自动售货类配方形态：能量消耗 + 产出 id + 产出数量 + 库存上限。
- 化学、制药、水培的职业与 Wilds 购买入口在 Demo 未开放。
- 资料基线：Demo 049-Rev5-L（Steam Build 25382790 / 0.46D），GAME_GUIDE 2026-09-14 快照，核对日 2026-10-02。

| 普通熔炉 | 共 2 份废金属或矿石 | 1 块金属锭 | 供电、夜间处理；三类金属原料可替换 |

### 触发与前置
- 熔炉需供电；处理在夜间结算。
- 水培需水 + 矿物质 + 电源 + 种子四件齐备。

## 机器运行与供电

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/machine-operation

### 机制要点
- 开工三条件：① 按设备要求准备能量信用或电力设施；② **原料必须放在机器库存中**；③ 检查设备状态与当前工序。
- 供电**按单台机器结算**：每台机器带运行时耗电标签 `machinery_drawn_power`（挂在机器物品上的数据标签，不是本地化文案键）。
- 系统先读该标签取得耗电量，再向**这台机器自己的外接电池槽**扣电；**槽位为空就无法开工**。
- 扣电是「按标签数值直接扣」，不做全店摊分。
- 机器另有内部蓄电池与状态：充能中、充能已暂停、电力不足无法充能、低功耗模式。遇到「装了电池却不动」先看这几项。
- 模组是可选性能调整，**不是所有生产都必须装模组**；停产先排查能源与材料，不要先买新模组。
- 普通涡轮增压器：**立即完成一次耗时工序**，一次性消耗；高级版可充能重复使用（充能所需天数未给出）。
- 拆机器只有两种工具：**等离子切割机**回收废金属、**剪线钳**回收线缆。**螺丝刀不能拆机器**——它拆完全报废的模组，并在垃圾场拾荒时提高螺丝产量。
- 夜间停工两类成因：① 欠缴电费被断电（结清恢复）；② 全站停电事件（等事件结束；有「偷接私电」能力可跳过）。两者都写进夜间日志。
- 无产物排查顺序：是否开始 → 能源与实际投料位置 → 设备损坏/工序是否适用 → 夜间停工（供电服务/停电日志）→ 设备自身电源与状态。
- 产量不符预期：查本批材料、实际工序、性能配置与输出情况。品质不符：查原料状态与工序要求，不要只堆性能。

### 表格 / 数值
| 环节 | 读取内容 | 判定结果 |
|---|---|---|
| 能否开机 | 机器物品上的耗电标签（整数） | 读不到该标签即无法供电 |
| 电池位置 | 机器自己的外接电池槽 | 槽位为空即无法供电 |
| 每轮扣电 | 同一个耗电标签的数值 | 按该数值直接扣电 |

| 供电设施 | 效果 |
|---|---|
| 能量阵列 | 店铺有电时，每晚为相邻电池或相邻可充电机器中的电池恢复 **2** 电量；解锁商用级供电后为 **4**，可叠加 |
| 充能器 | 店铺有电时，每晚为其中每块电池恢复 **3** 电量；解锁商用级供电后为 **6** |
| 涡轮增压器 | 立即完成一次耗时工序，使用后消耗 |
| 高级涡轮增压器 | 自动充能、不被消耗；充能天数未给出 |

| 日志文本 | 含义 | 恢复方式 |
|---|---|---|

| 发生了停电。电力供应中断了 | 全站停电事件 | 等事件结束；「偷接私电」可跳过 |

- 水产养殖更新（同页）：鱼缸 8×4 → 最大 12×8 格，储水箱始终 **12,000 毫升**。显示耗电量 = **max(1, 5 + 2W + 3H − 2E)**，W/H/E 为三种升级次数。
- 断电时夜间先扣活体最大健康的 **34%**；水量低于全缸需求 **50%** 会致死。
- 电鳗在亚成年/成年/大体型阶段每晚输出 **1/2/3 kJ**；汇总后先给本机充电，再分别尝试给相邻电池和相邻可充电机器充电，**各对象收到完整汇总输出、不平分**。

### 触发与前置
- 外接电池槽必须有电池，否则完全不工作（不是降速）。
- 能量阵列/充能器只在「店铺有电」时生效。

### 后果与风险
- 把「机器不产出」当成整店断电会误判：机器自身也有充能/低功耗状态。
- 用螺丝刀拆机器 → 拆不动，浪费时间。

### 与其他机制的关联
- 耗电与模组效率的关系见「机器模组」；RAS 耗电公式见「水产养殖」。

## 机器模组

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/machine-modules

### 机制要点
- 三项属性作用域：**性能** → 净水器每晚去除量、水分收集器产水量、水培生长速度、解序器速度、警报器防盗率；**效率** → 机器耗电（正值降低、负值增加）；**质量** → 净水器与熔炉纯度上限、水分收集器水质、水培产量上限。
- 熔炉说明写明**性能无效**；解序器与警报器说明写明**质量无效**。
- 通用耗电规则：**耗电量 = 基础耗电 − 基础耗电 × 合计效率 ÷ 100**。基础 100、效率 +32 → 68；效率 −44 → 144。实际扣电还受取整与机器自身规则影响。
- 质量先按目标机器系数换算，再进入该机器的品质/产量规则；**质量 +8 ≠ 纯度 +8 个百分点**。
- 节点通过相邻模组提供额外加成；改相邻物品后临时加成会重算，反复取放不会永久累积。
- 每件物品最多容纳 **2 个不同效果**；重复效果不叠加，互斥效果不能共存。普通模组默认随机分配 0~2 个效果；节点默认带 1 个辅助节点效果。
- 模组初始化：先按概率生成形状，再挂效果。**若未选择跳过剧情且天数 < 21，不挂载任何效果**；否则从 0/1/2 中随机取效果数。
- 形状概率：性能/效率/质量模组为四格 L 形 26/101、四格 T 形 25/101、四格 O 形 25/101、三格 L 形 25/101；超频/环保/精炼模组为四格 O 形 33/101、五格 U 形 34/101、五格 P 形 34/101。
- 「每次使用」= 安装它的机器实际工作一次，**不是开关界面或取放物品**；机器不工作不会因过了一天就成长/退化。
- 互斥：优质与劣质不能共存；自学习算法不能与优质、劣质、过载、退化、负反馈共存。
- 节点（小）与节点（中）三项基础属性均为 0，基础价值均 **50**，辅助比例同为 **20%**——中型节点不是更高倍率，只是接触面不同。
- 辅助节点 = 相邻模组「基础」属性合计的 20%，**不复制对方的临时加成**，也不能无限放大；负属性也会传给节点。
- 接收器方向相反：模组从相邻节点获得加成（每相邻一个节点 +10%）。
- 专用模组：警报传输模组（0 / −50 / 未确认，向指定派系传监控录像，同派系重复传不叠加）；熔炉模组（高炉）0 / −100 / 0，改投入产出比、纯度略降、不可叠加；熔炉模组（垃圾处理）0/0/0，垃圾→废金属；化学设备模块 0/0/0，用于搅拌机、加热板、化学成品机，装后需提取器拆除。
- 净水器与水分收集器接受通用模组；熔炉另接受熔炉专用模组；警报器另接受警报专用模组。
- 提取/修复：基础模组提取器**初始 6 次**使用，可无损取出卡住的模组，可用电子元件部分翻修；高级模组提取器不损耗，但**不负责修复已损坏的模组**。
- 模组舱扩建套件：一次性，符合条件普通机器最多扩建 **2 次**，每次机器基础价值 **+100**，不适用化学等特殊机器。
- 损坏模组可用电子元件尝试修复（无统一成功率）；报废模组用螺丝刀拆解回收，**不能当加成模组用**。

### 触发与前置
- 天数 < 21 且未跳过剧情 → 新造模组不带任何效果（开局前 3 周买模组等于买白板）。
- 专用模组只能装对应机器。

- 受限神经核心是原版物品，但「受限」表示有性能限制，携带前要查违禁状态。
- 用「质量 +8」推算纯度 +8% 会高估成品档位。

## 净水

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/water-purification

### 机制要点
- 水质六档（按纯度）：沟渠水 <90%（剧毒、严禁饮用）；铁锈水 90%~<96%（不安全）；幽灵水 96%~<98%（未经处理饮用不安全）；基础水 98%~<99%；优质水 99%~<99.9%；纯水 ≥99.9%。
- 判定**包含各档下限**：98.00% 已是基础水，99.00% 已是优质水，99.90% 已是纯水。
- 纯度整数 = **向下取整（水组分量 × 10,000 ÷ 液体总量）**；整数 ÷100 得百分数。例：9,899 表示 98.99%，仍为基础水。空容器返回 0（不代表沟渠水）。
- 无过滤、无溢出、无其他反应的混合可按体积加权估算；**混合本身不移除污染物**；净化移除污染组分时总液量可能同时减少，原料体积 ≠ 成品体积。
- 处理工具能力边界：滤水器（装水罐/过滤系统，倒水时过滤，只去杂质、微塑料、有机废物三类，**超过一定纯度阈值后不再生效**，阈值未给出）；净水药片（大量减少微生物、部分减少化学污染物，对其他污染物无效）；紫外线灯（对水容器使用，处理微生物，不能全面除杂）；净水器（放入储水容器 + 能量，过夜净化）；水分收集器（容器 + 能量，过夜产水）。
- 海德拉科技微型净水器：不论原水是什么都能拉到基础水级别，按净化量消耗耐久。
- 韧棉织物**织孔太粗、完全无法用于净水**（只在化学里做大颗粒粗滤）；水培芦苇滤芯可在过滤系统内去除特定污染物。
- 高级滤水器**每天开始时恢复 50 点耐久**。
- 自动售水机**只出售基础水、优质水和纯水**；售价额外 **+10%**，适用时再计入零售加价，**不受事件修正**。
- 排水管接水、锈水接水属于网络升级；拿到水源后仍需检测，纯度与杂质影响价值；脏水与错标水会在治安档案积累证据。
- 标签打印机只能编辑标签，不能替代净化。
- 净水器质量分档（见下表）：读的是**当前机器的质量加成**，不是待处理水的纯度。

### 触发与前置
- 净水器需：储水容器 + 能量 + 过夜。
- 微型净水器对已达 98% 的水**拒绝重复处理**；耐久不足时不处理整份水（不会自动净化一部分）。
- 微型净水器耐久消耗 = **向上取整（实际水量 ÷ 100 毫升）**：100ml→1；101ml→2；750ml→8；2,000ml→20；6,000ml→60。

### 后果与风险
- 普通过滤后纯度不再上升 → 已到滤水器生效上限，继续投耗材是纯浪费。
- 用标签冒充高档水 → 欺诈，积累治安证据。
- 净水器质量倍率 0.1 不等于「产出 10% 纯度的水」，它不是每晚净化百分比。

## 酿酒

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/brewing

### 机制要点
- 普通荧光莓果酿：荧光莓 + 水 + 酒瓶；**1 把浆果 → 低级酒，2 把 → 高级酒**。标准酵母不是必需品，但**强烈建议使用**。
- 开始发酵门槛：**至少 1 把荧光莓，且瓶内水量不少于 749 毫升**。放了合成酵母也允许开始（走伪酒线）。
- 发酵天数是写入酒瓶标签并每天结算倒计时的：基础 **4 天**，每天 `剩余天数 −= 酵母动力值`，归零即完成。
- 无酵母（野生酵母）动力值 1 → 4 天；标准/合成/酵母生物反应器动力值 2 → 2 天；超级酵母动力值 4 → 1 天。
- 「加速倍率」不是百分比，动力值就是每天额外扣掉的天数。
- 发酵本身**没有已确认的供电要求**；需要电力并彻夜运行的是后续催陈器。
- 品质分在**开始发酵时一次性结算**，逐项相加：每把浆果 −1/0/+1/+2（开局随机四态：发霉 −1、未熟 0、正常 +1、较小 +2）；浆果达到 2 把 **+1**；使用任意酵母（含合成酵母）**+1**；水质修正见表。
- 水质修正：纯水 +1、优质水 +1、基础水 0、幽灵水 −1、铁锈水 −2、沟水 −3。**代码里纯水与优质水同为 +1**，游戏内指南「纯水缺乏矿物质」的说法与实际数值不一致。
- 成品酒基础价值 **100**；品质分达 **5（臻品窖藏）及以上**额外归类为奢侈品。
- 品质档：0 及以下 难以下咽、1 粗桶劣酿、2 手工自酿、3–4 量产酒液、5 臻品窖藏、6 及以上 琼浆玉液。
- 伪酒（合成酵母）：改名**阴光莓果酿**，违禁等级 **2**，价值 **44**，带轻微致癌性。
- 催陈器：已完成发酵的酒 + 催陈器 + 能量 → 彻夜运行；每周期推进天数 = **⌊max(0, 质量加成) ÷ 125⌋ + 1**（每 125 点质量额外陈化 1 天）；质量加成 0 时恰为 1 天。
- 进催陈器条件：带酒容器标签、**不带赝品标签**、容器状态为「已发酵完成」。赝品酒会被拒绝。
- 四种酵母：标准酵母（动力 2 / 2 天 / 价值 10 / 品质分 +1）、超级酵母（动力 4 / 1 天 / 价值 20 / **无额外品质加成**）、合成酵母（动力 2 / 2 天 / 价值 8 / 非法物质，违禁等级 1，成品另算）、酵母生物反应器（动力 2 / 2 天 / 价值 250 / **发酵开始时退回物品栏、不被消耗**）。
- 继续陈化会占用物品与空间；没有核实完整价格曲线前不宜设定通用最佳陈化天数。
- Wilds 网络包含酿酒师与葡萄酒酿造项目，试玩版限制需购买前核对。

## 模式、Demo 范围与结局

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/game-modes-and-endings

### 机制要点
- Demo 菜单放行的四种开局：**学徒、养鼠人、Rock Bottom（一无所有）、水商**。其他职业保留档案但标注「Demo 未开放」——有说明不代表能选。

## 彩票与赌博

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/lottery-and-gambling
- 补充：https://probably-stolen.nicokobo.com/zh/items/scratcher（物品页，含概率公式）

### 机制要点
- 刮刮乐：刮开三个区域，按相同图案结算。**三连按三连档支付，不再叠加两连奖金**。
- 奖金：两个相同普通图案 **10**；两个营养果图案 **30**；三个相同普通图案 **75**；三个营养果图案 **350**；无相同图案 **0**。
- 一叠刮刮乐含 **5 张**，逐张开奖。中奖票可立即兑换（配给站或对应兑换人员）；**配给站支付信用点，不是食品券**。未刮完、未中奖、已兑换的票不能再领。
- 三个区域可能图案：营养果、泥炭合成肉、繁星果糊、猫咪巧克力棒（四种）。
- 彩票在**获取时**各区域图案已确定，不是刮开时确定——除非人物幸运值提升（未刮开的票有在幸运更高时重抽图案的逻辑；一旦开始刮就不走这条分支）。
- 概率系数 **m = 幸运值 ÷ 100 + 1**；人物默认幸运值 0 → **默认 m = 1**。
- 默认幸运值下**获得奖金的期望为 12.67 信用点**，**不如卖给商人获得 17 信用点**；**幸运值 > 23** 时期望才超过 17。
- 组合概率（m=1）：三个营养果 0.8%→350；三个相同其他 3.2%→75；两个营养果 10.7%→30；两个相同其他 42.7%→10；其他 42.7%→0。
- 每周彩票：**每周六早晨开奖**，报纸公布中奖号码。选号 **1–49**，中奖号码为六个不重复数字。
- 每周彩票奖金档：匹配 0–1 → **0**；2 → **35**；3 → **300**；4 → **2,500**；5 → **100,000**；6 → **1,000,000**。
- 注意版本冲突：游戏说明仍写「至少匹配三个数字」，但原生计算存在两号档（35 信用点）；兑奖以实际中奖标记与显示金额为准。
- 赌博成瘾会让玩家在交易中**自动购买可用的彩票**（含刮刮乐与成叠票）；它与尼古丁/酒精/麻醉品戒断的 **3/20 夜**计数不同。
- 刮刮乐获取途径：垃圾场拾荒概率获得、顾客、拆开一叠（5 张）、开启治安部物证柜概率获得。
- 彩票购买价格、每期彩票价格、完整奖池与期望收益曲线**页面未给出**，不能从奖池最大值推断平均利润。

## 采购接单与交货

- URL: https://probably-stolen.nicokobo.com/zh/wiki/intents/procurement-orders

### 机制要点
- 普通采购有**两个阶段**：「采购要约」（接单）与「采购交货」（交付）。
- 采购凭单数据包含：**客户名、订单正文、日期、最终报酬**。
- 接单前四项核对：所需货物（具体物品 + 数量 + 对话要求的品质或其他条件）、交付时间（按本单日期备货，**不假定所有订单都是次日交货**）、报酬（按本单报价核算购入与加工成本，**不拿图鉴基础价值代替合同报价**）、缺货风险（比较现货、生产耗时与电话送货时间）。
- 交付：核对客户与凭单，把要求的货放到柜台，按本次交付界面检查是否满足条件再确认。
- **普通向顾客出售商品不能自动视作采购订单已完成**。
- 页面明确：**没有完整证明所有订单共用统一的订金、违约罚款或固定期限**；具体数量、日期与奖励以实际凭单和对话为准。
- 不要与其他订单混淆：电话供货（你向供应商买货）、枪匠订单（定制枪械）、卡特尔交货（持续的数量与纯度配额）——三者不套用同一交付规则。

### 表格 / 数值
| 核对项 | 操作建议 |
|---|---|
| 所需货物 | 记录具体物品、数量及对话要求的品质/条件 |
| 交付时间 | 按本单日期备货，不假定次日交货 |
| 报酬 | 按本单报价核算成本，不用图鉴基础价值代替 |
| 缺货风险 | 比较现货、生产耗时与电话送货时间 |

### 后果与风险
- 按「所有订单次日交货」备货 → 可能误判可接单量。
- 把普通柜台成交当成交付 → 订单不结算。

### 与其他机制的关联
- 电话供货见 suppliers-and-wholesale；卡特尔配额见 cartel-deliveries；枪匠见 gunsmith-orders。

### 原文关键句
> 「普通向顾客出售商品不能自动视作采购订单已完成。」
> 「不要套用统一的订金、违约罚款或固定期限。」
