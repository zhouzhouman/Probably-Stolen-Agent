## 店铺布局

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/shop-layout

### 机制要点
- 五类空间不是同义词：议价柜台（拖入待买卖物品）、展示柜（陈列吸引买家）、储藏区（收纳待售货与原料）、机器区（放机器，且必须把原料与能源放进对应槽位）、走私者暗格（避开检查）。
- 柜台只是「准备交易」：把物品拖到柜台或 Ctrl＋单击快速转移，转移不等于成交，仍需完成议价与确认。
- 展示柜位于卷帘门左侧；开门前摆好才当天生效，营业后新增的陈列次日才生效。
- 简易储物舱、枪匠储物舱、化学家储物舱的说明明确限制：不能放入其他容器或机器。收纳失败时先看容器规则，再判断是否只是格子不足。
- 垃圾桶用于丢弃，或作为已解锁地下交易所要求的交货物；支付清洁服务后会清空，不能当临时仓库。
- 能量方块（PowerBloc）：店内已供电时，每晚为相邻的能量电池、或相邻机器内的能量电池恢复 2 点电量；解锁商用级供电单元后为 4 点。充电器不属于该相邻机器目标；多个能量方块效果可叠加。
- 该充电量于 2026-10-22 对原版 Demo Steam Build 26017150 静态核对，未做游戏内实测。
- 充电器用于给「装入其中的电池」充电，与能量方块的相邻判定是两套目标。
- 建议整理顺序：待鉴定货 → 已确认可售货 → 下批原料 → 夜间产物（手动分区建议，非游戏强制）。
- 展柜扩建增加陈列空间与「展示商品吸引的买家」；店铺翻新 I–III 提升的是基础吸引力，不等于增加库存格子。二者不可互换理解。
- 外出前给柜台留出空间，否则带回的物品没有位置接收。
- 吸引力公式：翻新基础吸引力 B，投影设备加成 P；脏乱等级 G ≤ 2 时吸引力 = B＋P；G > 2 时扣「基础值的 G×5%」并截去扣减值小数，再加 P。不是把总吸引力整体打折。
- 走私者暗格内的物品会被普通夜间盗窃候选筛选排除；但普通储物舱不能据此视作保险箱（暗格才是）。
- 「强制可抵押」标签是特殊例外，会先通过筛选；其他失物事件另有规则。

### 表格 / 数值
| 项目 | 数值 | 说明 |
|---|---:|---|
| 能量方块（相邻电池） | +2 电量/晚 | 商用级供电后 +4 |
| 充电器（内部电池） | +3 电量/晚 | 商用级供电后 +6（见电力服务页） |
| 脏乱免罚阈值 | G ≤ 2 | G > 2 起扣基础吸引力的 5%/级 |
| 翻新等级 | I–III | 提升基础吸引力 B，不加格子 |

### 触发与前置
- 展示柜陈列只在「开门前」摆放才当日生效。
- 能量方块充电需「店内当晚已供电」＋电池确实装入目标设备。
- 展柜扩建与店铺翻新是两类不同的升级项。

### 后果与风险
- 把违禁品摆进展柜会直接引来盘查/逮捕（见展示柜页）。
- 暗格标签可能因搬动/重摆而丢失（见物品藏匿页），搬完必须复核位置。

### 与其他机制的关联
- 展示柜容量与客源：`/zh/wiki/terms/showcase`
- 清洁服务与脏乱等级：`/zh/wiki/services/janitorial-service`
- 夜间盗窃候选筛选：`/zh/wiki/terms/theft-and-insurance`
- 暗格：`/zh/wiki/terms/concealing-goods`

### 原文关键句
> 展柜扩建增加陈列空间与展示商品吸引的买家；店铺翻新 I–III 的说明则是提升基础吸引力，不应把翻新当成增加库存格子的同义词。
> 走私者暗格中的物品还会被普通夜间盗窃候选筛选排除；普通储物舱不能据此视作保险箱。

## 展示柜

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/showcase

### 机制要点
- 每天开门时，游戏按「店铺当时状态」安排客源；开门后才加入的展示物次日才生效。布置完再看客源界面（Clientele）。
- 陈列普通可售商品 → 吸引「想买该类商品」的买家；陈列总价值同时影响买家的预算与阶层。
- 霓虹灯牌（水/食品/医疗/材料等）吸引「向你出售该品类」的卖家，用于补货，需预留收购资金与储物空间。
- 枪械许可证吸引买枪顾客，但仍须核对持证条件——陈列不能替代有效许可。
- 鉴定委员会初级证书 → 吸引需要鉴定服务的顾客。
- 拾荒者信物：每枚放入展示柜都提高拾荒者到访几率，具体概率不固定写死。
- 暗灯 → 让小偷得知本店收赃，用于接触赃物货源；响应几率受黑市声望影响，不能保证替你买走赃物。
- 远征招募牌 → 吸引新雇员与准备远征的现有雇员（受版本与进度开放限制）。
- 基础展示柜：导师说明为每天吸引 1 位相应买家。
- 名额公式：普通商品从 1 个名额起算；「正在使用买家介绍」「已解锁展柜 I」「已解锁展柜 II」每满足一项 +1，最多 4 个。
- 门面遭破坏时名额直接回到 1，前述加成全部不计入。
- 品类价值 = 该品类展品价值之和；只统计主类型，共 11 类：食品、医疗、材料、日用品、管制药物、武器、护甲、工具、模组、弹药、水。
- 一件物品的多个标签会分别计入各自品类；带「水配给」标签的展品额外计入水。
- 选取规则：品类价值降序，最多取「名额」个，且只保留价值 > 0 的品类，每个入选品类生成一位买家。重复摆同类商品是提高该品类排序竞争力，不是每件各加一位买家。
- 同分品类按「陈列顺序」决定先后，不是随机。
- 来客档位判定顺序：① 内部日计数 D ≥ 14 且品类价值 ≥ 350（日用品 ≥ 300）→ 高价档；② 未进高价档且（品类价值 ≥ 145 或店铺吸引力 ≥ 400）→ 中价档；③ 其余 → 默认档。
- 水类另有分支：柜内最常见的水类型影响实际来客；最常见为纯水时直接是「囤水者」。
- 武器默认来客、管制药物各档来客都只有一位，因此结果确定；其余品类默认档在池内等概率抽取。
- 当日吸引力 < 100 时不会生成展示柜买家；非跳过开场的新档，第 1 天也不安排。
- 脏乱扣吸引力：G ≤ 2 不扣；G > 2 扣基础吸引力的 5%/级（截小数），再叠加投影设备加成。
- **不要把违禁品放进展示柜**：导师笔记明确警告会招致逮捕；检查对话有「看见展示柜内可疑物品后进行全面检查」的分支；展示柜不具备暗格的藏匿作用。
- 名额是「选取品类的上限」，不保证来客数或成交数；顾客仍有预算与需求限制。

### 触发与前置
- 每日开门时结算客源；营业中新增陈列次日生效。
- 名额加成需「正在使用买家介绍」或已解锁对应展柜等级。

### 后果与风险
- 展柜放违禁品 → 触发全面检查分支（可直接导致逮捕）。
- 只堆展示物不清洁 → 吸引力 < 100 时买家直接归零。
- 品类价值集中才能抢到名额；分散摆法等于每类都排不上。

### 与其他机制的关联
- 布局与脏乱：`/zh/wiki/terms/shop-layout`、`/zh/wiki/services/janitorial-service`
- 赃物销路（暗灯）：`/zh/wiki/terms/stolen-goods`
- 盘查（展示柜检查）：`/zh/wiki/terms/inspections`

### 原文关键句
> 普通商品争取买家名额时，先从 1 个名额起算；正在使用买家介绍、已解锁展柜 I、已解锁展柜 II，每满足一项再加 1，最多 4 个。门面遭破坏时直接回到 1 个名额。
> 不要把违禁品放进展示柜。导师笔记明确警告会招致逮捕。

## 防盗与保险

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/theft-and-insurance

### 机制要点
- 分工：警报降低「普通夜间盗窃」风险（需独立电源 + 启用状态）；保险负责当晚失窃后的「次晨追回」。警报可能失效，保险不阻止入室。
- 缴纳店铺电费 ≠ 警报已装独立电源，二者必须分开核对。
- 警报说明书：模组效率对应耗电，性能对应防盗率加成；品质对这项模组效果无影响。
- 下层区「被针对」会提高被小偷盯上的频率与保险费用；黑市「拒保」会关闭保险服务。
- 柜台下的「治安呼叫按钮」（举报当前顾客）与夜间警报是两套设备，举报不能当免电防盗。
- 普通未投保分支共 5 步，任一提前返回都不进入失窃掷骰：
  1. 保险服务未解锁 / 卡特尔保护启用 / 拥有 Alert 天赋 → 提前返回。
  2. 当晚已投保 → 走追回日志分支，连续未投保夜数清零。
  3. 未投保且未提前返回 → N 加 1，算事件率。
  4. 掷骰通过且警报有效 → 再掷一次是否被警报拦截。
  5. 事件通过且警报未拦截 → 从可盗候选随机选一件；没有候选则不丢货。
- 事件率（阈值）算法：游戏抽 0–99 整数，小于最终阈值才通过；阈值 < 0 按 0%，> 100 按 100%。
- 阈值调整顺序：基础 33；下层区「被针对」则改为 66；治安贵宾（SEC_VIP）覆盖为 −100000；再加「5 × N」（N 已含当晚）；治安保护生效再减 16。
- 首个未投保夜晚 N＝1 时事件率 38%；第 14 晚达到 100%。这只是第 3 步，不是最终丢货率。
- 警报拦截：显示值 = 50 ＋ 当前性能加成，最低显示 0；实际拦截概率比显示值多 1 个百分点，最高 100%。显示 50 → 拦截 51%；显示 99 已能拦截全部随机结果。
- 候选筛选：排除文件、容器本体、机器、当前价值为 0 的物品；走私者暗格内的物品也排除；带「重要/锁定/锁后物品/卡住模组」等保护标签的排除；父库存同时禁止放入与取出的排除。
- 特殊例外：带「强制可抵押」标签的物品会先通过筛选。
- 容器本体被排除，不代表其内容物都受保护。
- 算例：首晚触发率 38%、有效警报显示 50、有候选且无特殊分支 → 穿过两次判定概率 = 38% × 49% = 18.62%。这是带前置条件的算例，不是全局统一失窃率。

### 表格 / 数值
| 项目 | 数值 | 说明 |
|---|---:|---|
| 事件率基础 | 33 | 被针对时改为 66 |
| SEC_VIP 覆盖 | −100000 | 直接不触发 |
| 未投保累计 | +5 × N | N 含当晚 |
| 治安保护 | −16 | 最后减 |
| N＝1 事件率 | 38% | N＝14 达 100% |
| 警报显示基准 | 50 + 性能加成 | 最低 0 |
| 实际拦截 | 显示值 +1pp | 上限 100% |
| 算例总概率 | 18.62% | 38% × 49% |

### 触发与前置
- 警报需独立电源 + 启用；电费缴纳不覆盖。
- 提前返回条件：保险未解锁 / 卡特尔保护 / Alert 天赋 / 当晚已投保。

### 后果与风险
- 警报可能「掷骰通过了但没拦住」，不是保险式兜底。
- 没有候选（全在暗格、全是文件/容器/机器）时该池不会丢货。
- 被针对状态下阈值从 33 直接翻到 66。

### 与其他机制的关联
- 保险费用与返还：`/zh/wiki/services/insurance-service`
- 电力与充电：`/zh/wiki/services/power-service`
- 暗格：`/zh/wiki/terms/concealing-goods`

### 原文关键句
> 无修正时，首个未投保夜晚 N＝1，事件率为 38%；第 14 晚达到 100%。
> 实际拦截概率比显示值多 1 个百分点，最高按 100% 处理。

## 检查

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/inspections

### 机制要点
- 盘查不是固定日程：走私与销赃的累计金额（犯罪额）达到门槛后，治安部才开始排期；金额越高、间隔越短。
- 排期门槛：走私＋销赃累计犯罪额 ≥ 50 信用点，低于该值不排期。
- 间隔按同一指标分 6 档（见下表），单位「天」。
- 三项治安部特权改写间隔：「彻底检查」更频繁，「信任」更稀少，「贵宾」完全不再接受盘查。
- 特权修正原文：「信任在此基础上上下限各 +2 / +4，彻底检查各 −1，最终下限不低于 1 天、上限不低于 2 天」。（哪一端对应 +2、哪一端对应 +4 原文未逐一对应，实施时不要硬编码。）
- 盘查按容器逐层扫描。带藏匿标签的容器整棵子树只登记为「已藏匿」，内部物品不再逐件检查；上锁或锁在柜台后的物品同样计入藏匿。
- 盘查员三类：普通、可疑、懒散。懒散盘查员不会打开展示柜。
- 处置按「被查获物品中最严重的一件」结算：高危级 → 无宽限时查封店铺并逮捕，有宽限时改走宽限对话并扣声望（但不保证保留查获货物）；高级 → 没收并罚款；中级 → 没收；只有赃物 → 没收赃物；低级 → 口头警告；什么都没查到 → 治安部声望 +3。
- 罚款算法：被查获物品的「单位价值」逐件相加，不是只看最严重那一件。
- 声望扣分逐件算再合计：基础 1 点；违禁等级 无/低/中/高/高危 = 0/1/2/3/4；赃物基础价值 <18 或非赃物 = 0，18–49/50–84/85–139/≥140 = 1/2/3/4。
- 同一件货同时是违禁品与赃物时，两部分都计入。所有分数相加后单次最多扣 25 点。
- 清白奖励 +3 的例外：本次只要有物品被藏匿，就不再发放。
- 贿赂：金额与物品价值无关，随治安部声望升高而降低；公式 100 ＋（店铺天数 − 治安部声望）×2，限制在 40–400 信用点。
- 两个小概率变量：赃物按热度掷点（热度越低越可能漏检）；幸运判定有机会让整次盘查忽略全部违禁品。都不能当稳定方案。
- 盘查预警：线人在界面提示「两天后 / 明天 / 即将开始」时各发一条夜间日志，对应内部倒计时 3 / 2 / 1。只覆盖常规盘查，突击盘查不在其中；贵宾不受盘查，也就没有预警。
- 与「赝品对质」是两套机制：放大镜真伪检查 + 对质属于赝品系统，不是治安部盘查。
- 举报奖励（同一页给出）：中级/高级/高危级分别为 25/40/60，另加赃物成交价的 4%。
- 拾荒者拒收违禁品概率 = 25 − 下层区声望 ÷ 4（这是拒收判定，不是治安罚款）。

## 通缉与举报

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/wanted-and-reporting

### 机制要点
- 举报通过「柜台的报警器」发起，不是对话选项。同一名顾客只能被举报一次，重复尝试会被界面拒绝。
- 四类结果：通缉犯、违禁品贩子、赃物卖家、误报。
- 通缉犯：按名单赏金结算，治安部声望固定 +5。
- 违禁品贩子/赃物卖家：按交出的货物计价；声望按其中最高违禁等级提高；只有赃物、没有违禁等级时这部分声望为 0。
- 小偷：按同一规则结算，但等级奖励为 0。
- 误报：治安部声望 −8；余额 ≥ 100 时罚款 50；并累计误报次数。
- 只有名单上的顾客才按赏金结算。改造体扫描仪确认的身份与通缉判定无关，扫描结果不能替代核对名单。

- 诱饵顾客：只想来买食物、不带通缉标记；把诱饵当通缉犯举报 = 误报。

## 违禁品

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/contraband

### 机制要点
- 四档：低级、中级、高级、高危级。等级同时决定「加价幅度」与「盘查被查获后的处置」。
- 处置：低级 → 通常被治安部无视，若进入查获清单则口头警告；中级 → 没收；高级 → 没收并罚款；高危级 → 查封店铺并立即逮捕。
- 只要在盘查中被查获违禁品，治安部声望都会下降。
- 四级加价是存档里可配置的数值，不是写死常量；默认值：低 +35%、中 +70%、高 +100%、高危级 +200%。
- 同一件违禁品还有对应「折扣特征」，用于特定情形反向调价（默认 −17% / −35% / −50% / −100%）。
- 交易声望的严重违禁品倍率只从中级开始：中级 ×2.0、高级 ×2.5、高危级 ×3.0；低级没有 ×1.5 这一档。
- 等级内部按 0–4 取值（无、低级、中级、高级、高危级）。
- 枪证三级分别覆盖低级、中级、高级违禁枪械；高危级武器没有任何许可可以合法化。
- 管制等级与违禁等级是两套标记：一件物品可以「只是管制」，也可以「同时是违禁品」。
- 违禁描述的是「管制属性」，赃物描述的是「来源」，两者可以同时存在，检查时分头确认。
- 收购前依次核对：合法性 → 需要的许可 → 能否存放（有无暗格及实际位置）→ 是否有买家 → 现金能撑到什么时候。
- 高加价商品若一直卖不掉，会占用本应支付租金、能源与原料的钱。

### 表格 / 数值
| 等级 | 默认加价 | 折扣特征 | 盘查处置 | 交易声望倍率 |
|---|---:|---:|---|---:|
| 低级 | +35% | −17% | 口头警告 | 无（无 ×1.5） |
| 中级 | +70% | −35% | 没收 | ×2.0 |
| 高级 | +100% | −50% | 没收并罚款 | ×2.5 |
| 高危级 | +200% | −100% | 查封店铺并逮捕 | ×3.0 |

### 触发与前置
- 持有对应等级枪证才能合法持有低/中/高级违禁枪械。
- 需要专用藏匿设施（暗格）才可能避开扣押。

### 后果与风险
- 高危级无许可可救，唯一出路是别让它进入查获清单。
- 加价可配置：换版本/存档可能不是 35/70/100/200。

### 与其他机制的关联
- 处置与声望：`/zh/wiki/terms/inspections`
- 藏匿：`/zh/wiki/terms/concealing-goods`
- 犯罪入账：`/zh/wiki/terms/crime-and-investigation`

### 原文关键句
> 四级加价是存档里的可配置数值，不是写死的常量；默认值即攻略常见的低 35%、中 70%、高 100%、高危级 200%。
> 枪证只覆盖低级、中级、高级违禁枪械，高危级武器没有任何许可可以合法化。

## 赃物

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/stolen-goods

### 机制要点
- 每件赃物带热度值，同时决定三件事：买入折价、盘查认出概率、卖出时获得的交易声望。
- 热度初始值由物品基础价值分档决定：≤17 不标记为赃物；18–49 → 25；50–84 → 50；85–139 → 75；≥140 → 100。
- 热度更新会降低热度：无违禁标签 −18；低/中/高/高危级依次 −16 / −14 / −12 / −10；降到 0 后移除赃物标记。
- 静态证据没有定位该更新函数的调用频率，**不能写成固定「每天一次」**。
- 买入是「折价」不是加价，按热度分四档：≤25 → −10%；≤50 → −15%；≤75 → −20%；>75 → −25%。
- 卖出交易声望倍率：≤25 → ×1.5；≤50 → ×2.0；≤75 → ×2.5；>75 → ×3.0。
- 盘查认出：热度百分比即认出概率；赃物若同时带违禁标记，则不再单独掷这一次点。
- 「把热度直接设为 100」的调用已在柜台与展示柜治安检查中确认；普通容器扫描是否也走同一重置路径尚未证实。
- 暗灯放展示柜可吸引销赃客，成功率由灯数、目标类型、黑市声望共同决定；黑市声望同时影响卖赃物的交易声望倍率。
- 藏匿只处理「位置」，不清除治安档案里已积累的调查进度。

### 表格 / 数值
| 基础价值 | 初始热度 |
|---|---:|
| ≤ 17 | 不标记为赃物 |
| 18–49 | 25 |
| 50–84 | 50 |
| 85–139 | 75 |
| ≥ 140 | 100 |

| 热度档 | 买入折价 | 卖出交易声望倍率 |
|---|---:|---:|
| ≤ 25 | −10% | ×1.5 |
| ≤ 50 | −15% | ×2.0 |
| ≤ 75 | −20% | ×2.5 |
| > 75 | −25% | ×3.0 |

| 条件 | 每次更新降温 |
|---|---:|
| 无违禁标签 | −18 |
| 低级 | −16 |
| 中级 | −14 |
| 高级 | −12 |
| 高危级 | −10 |

### 触发与前置
- 热度 ≤17 的物品买进来不带赃物标记（可直接上架）。
- 柜台/展示柜治安检查认出后热度直接置 100。

### 后果与风险
- 高热度货买入最便宜（−25%）但最难脱手、盘查认出率最高。
- 降温频率未确认，不要按「放一晚就降」做计划。

### 与其他机制的关联
- 盘查：`/zh/wiki/terms/inspections`
- 犯罪入账（议定价值 × 热度 ÷ 100）：`/zh/wiki/terms/crime-and-investigation`
- 暗格：`/zh/wiki/terms/concealing-goods`

> 盘查按热度掷点，热度百分比即认出概率；赃物若同时带有违禁标记，则不再单独掷这一次点。
> 现有静态证据没有定位这个更新函数的调用频率，不能写成固定「每天一次」。

## 物品藏匿

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/concealing-goods

### 机制要点
- 走私暗格有三种变体：smuggler_bay（走私者暗格，基础价值 300）、smuggler_bay_mini（迷你走私舱，250）、smuggler_bay_mod（走私者暗格（改进），850）。
- 三个变体的**容量数值不在代码里**，以物品界面显示的可用空间为准。
- 普通储物容器、机器内部、柜台不会因为外观相似而获得暗格效果。
- 判定只认三个标签：藏匿标签（暗格容器，盘查跳过整棵子树）、锁后标签（物品放在柜台之后并上锁）、上锁标签（物品处于上锁状态）。
- 盘查遇到带藏匿标签的容器时，整棵子树只登记为「已藏匿」，内部违禁品不进扣押清单；上锁或锁在柜台后的物品也计入藏匿。

- 代码中存在一处摆放回调会移除暗格的藏匿标签，但静态证据不足以精确归因到「拆除」还是「移走」。搬动/重摆/整理库存后必须按实际标签与位置复核。
- 水培走私模组说明声称会移除「生长中种子」的违禁状态；实际执行点尚未定位，不要把说明文本当已验证触发时机。它改的是物品标记，与暗格是两套东西。

## 犯罪记录与调查进度

- URL: https://probably-stolen.nicokobo.com/zh/wiki/terms/crime-and-investigation

### 机制要点
- 两个数值：**犯罪总值 C**（各项当前犯罪记录合计）与 **调查进度 E**（独立累积，上限 100）。
- 成交后留下的历史记录不会因为把货藏起来或卖空而自动消失。
- 总值 <100 时档案显示「不适用」，这只是显示条件，不代表以前累积的进度清零。正式清案才会把各项当前犯罪额、调查进度、案件派发状态归零。
- 销售带违禁标签的物品：以该物品的「议定价值」计入相应走私罪名；药物、武器、门禁卡等分别归类。
- 销售赃物：先算「议定价值 × 赃物热度 ÷ 100」，取整后计入销赃。同一件货同时是赃物和违禁品时，两部分都可能入账。
- 派系修正（入账前）：黑市顾客 ÷2；革命军顾客 ÷3；下层区顾客且已解锁「守口如瓶」÷2；卡特尔顾客归零；其它普通分支保留原值。均舍去小数。
- 天赋修正：「威慑」×约 0.67 取整；「大嘴巴」×约 1.33 取整。同时具备时按上述顺序分别取整。
- 取整规则：常规取最近整数，恰落半整数取偶数（2.5→2、3.5→4）。
- 减免属于「记录计算」，不改变商品的违禁属性或持证要求。
- 每日结算顺序：先看结算前 E；E < 80 时每条犯罪记录 −20（最低 0）；E ≥ 80 时停止自然衰减；再按衰减后的总值取基础增长。
- 基础增长档位：0–99 → +0；100–299 → +2；300–849 → +6；850–1199 → +9；1200–1499 → +12；1500–2499 → +20；≥2500 → +33。
- 特权修正顺序：① 治安部「值得信赖」先减半并舍去小数；②「头号通缉」×1.5 取整，若没有但有「重点盯防」则 ×约 1.2 取整（同一分支）；③ 上层区「联名检举」再 ×1.5 取整。修正后加入 E，达到 100 封顶。
- 案件尚未派员且当前犯罪总值 >0 时，会排入治安官来访；排队不等于当场判罚。
- 算例：结算前两项 340 与 180，E=30，无特权 → 各减 20 得 320+160=480，落 +6 档，结算后 E=36。若结算前 E ≥ 80 则不再各减 20。

- 摆平者算例：400 与 200 → 290 与 120，总值 600 → 410。不能把 600 合并后只减一次固定 50。
