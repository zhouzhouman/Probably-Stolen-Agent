### 0.2 本地知识库的版本事实

`knowledge/wiki_raw/_SPEC.md` 抓取于 **2026-10-24**，即正式版发售（**2026-10-28**）前 4 天，源站是 Demo Build 25382790 / 26017150；`/zh/wiki/terms/*` 多条路径现已返回「词条不存在」。`knowledge/mechanics/` 的 203 张卡由它派生，`artifacts/knowledge_review.md` 判定「200 张 / 高风险 158」。
**结论：本地卡的数值不得直接写进新接口实现或提示词，必须先按 §0.3 校正。**

## 2. 逐机制接口矩阵

> 「现状」列中 `A:` = `POST /action` 的动作名，`S:` = `GET /state` 或其他只读端点字段，`O:` = `visible_info` 观察层字段，`P:` = Python 侧逻辑。
> 优先级：**P0** 阻断/口径错误 → **P1** 核心闭环正确性 → **P2** 覆盖率扩展 → **P3** 冻结/暂缓。

## 3. 统一接口规范（所有新增接口必须遵守）

### 3.1 命名与形态

- **动作**：全部走 `POST /action`，body `{"action":"<snake_case>", ...params}`；动作名在 `contracts.py` 注册后才进入 `ACTIONS`。
- **只读端点**：`GET /<domain>` 或 `GET /<domain>/<sub>`；**统一响应** `{"ok":true, "<domain>":…}` 或 `{"ok":false,"error":"…","code":"…"}`。
- **状态字段**：`GET /state` 只放高频、小体积、决策必需字段；大清单（网络目录、展示柜、机器配方、队列名单）一律独立端点，按需拉取。
- **参数**：禁止数组 / 对象参数（当前 `ExtractValue` 不支持）；必需参数在 `schema.py` 声明并由 `validate_decision` 校验；`occurrence` 用于同类对象消歧，统一从 0 开始。

### 3.2 错误码（新增，替代纯中文文案）

| code | 含义 | AI 应做的事 |
|---|---|---|
| `NOT_UNLOCKED` | 机制未解锁 | 生成解锁前置动作，禁止重试本动作 |
| `VERSION_NOT_SHIPPED` | 官方版本未实装（远征/雇工） | 永久从候选排除，直到 `/expedition.unlocked=true` |
| `PRECONDITION` | 前置状态不满足（弹窗/昼夜/界面） | 生成关闭/推进动作 |
| `INSUFFICIENT_FUNDS` | 现金/恩惠不足，含 `required/available` | 转清库存 / 停止采购 |
| `UI_NOT_READY` | 自绘界面未打开或元素未找到 | 先 `open_*` 再重试 |
| `REFLECTION_MISSING` | 反射字段缺失（游戏改版） | 停止依赖该字段的决策，报警 |
| `IDEMPOTENT_REPLAY` | 幂等键重复 | 视为成功，不再重试 |

错误响应必须带 `hint`（可执行的下一步），使 `detail` 回灌模型后能直接改选动作。

### 3.3 成功判定铁律（沿用项目既有准绳，不得放宽）

1. **只认状态变化**：现金 diff / 库存 diff / day diff，不认 `ok=true`。
2. **异步转场**：`go_out` / `leave_outside` 只发起 `Travel`，落地靠下一轮 `/state.night.in_transit` 判断；连续两步必须被 `_night_ui_guard` 拦截。
3. **金额类动作**（`wilds_purchase` / `buy_store` / `appraise_submit` / `pay_rent`）必须带幂等键 + 二次确认，且用现金 diff 验证，防重复扣款（历史事故 r38 双扣 −400）。
4. **玩家视角**：`features` 未验出时只给 `publicDisplay` / `fakeCondition`，不吐 `realCondition`；配方产出不静态预测。**不得为方便 AI 而作弊**。
5. **能力合规**：任何新增的 `Process.Start` / `ThreadPool` / 第三方库补丁都会触发扫描器拒绝；后台任务一律走 `ModHelper`。

### 3.4 契约一致性检查（每次构建前）

```
GET /contract  →  {version, actions:[{name, params[], phase, model_visible, implemented}], state_fields:[…]}
contracts.py   →  同名集合
断言：C# actions ⊇ Python ACTIONS；Python ACTIONS ⊇ BRIDGE_ACTION_PARAMS ∪ {force_dismiss}
      state_fields ⊇ observer 引用的全部 state.* 路径
失败即拒启动（而不是静默降级）
```

## 4. 明确「决定不做」清单（写进提示词，防止子智能体造必然失败接口）

| 机制 | 不做的理由 |
|---|---|
| `buy_lottery` | 反编译源码找不到购票入口（`LotteryHelper` 只有标签与刮奖） |
| 战斗瞄准 / 自动射击 Aug | `--no-mouse` 下无法瞄准；保留 `shooting` 只读状态 |
| `load_save` 进 AI 白名单 | 读档整体重置内存状态，误用毁进度；只开放人工 CLI |
| `open_container` | 容器内容已作为 `children[]` 输出，开箱只开窗口无状态变化 |
| `toggle_power` 日间切电 | 电源由夜间 `POWER_SERVICE` 驱动，日间不可切；删除死代码 |
| 机器配方产出预测 | `craftFunc` 运行时计算，静态编造比不给更糟 |
| 真伪 / 真实品相无条件暴露 | 等于让 AI 白嫖验货 |
| 远征 / 雇工派遣 | 官方 1.0 未实装（见裁决 A） |
| 派系态势 `FactionStatus` | 正式版源码中无任何引用点，无状态可暴露 |
